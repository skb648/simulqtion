# Reality Compiler

AI-powered Reality → Digital Twin → Interactive Simulation.

This repository is the production foundation for the first vertical slice: **DC motor**.

## Current milestone

Camera scan → guided multi-view capture → backend-assisted motor reconstruction metadata → uncertainty-aware digital twin → physically meaningful DC motor simulation → baseline/experiment comparison.

The implementation deliberately distinguishes `OBSERVED`, `INFERRED`, `HYPOTHESIS`, `ESTIMATED`, and `UNKNOWN` information. Hidden geometry is never fabricated.
